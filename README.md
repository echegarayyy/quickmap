QuickMap es un frontend gráfico diseñado para simplificar auditorías de red
y buscar optimizar el flujo de trabajo focalizando el uso del pad numérico, 
de manera que se pueda introducir y escanear direcciones de forma eficiente.
*Naturalmente, para que la interfaz brille, se debe contar con un pad numérico en el teclado.*

Características Principales.

- Uso de threading para evitar "congelamientos" de la interfaz durante escaneos exigentes.
- CLI con parseo inteligente de argumentos para introducir comandos manualmente.
- Instalador completo de la interfaz y sus dependencias, todo empaquetado y listo para instalar gracias al software Inno.

[Manual]

Enter - Escanear.
Supr. - Limpiar.
F12 - Guardar Log.
F1 - Escaneo Rápido. 
F2 - Escaneo Intenso.
F3 - Ping Sweep.

F5 - Ingresar a terminal. (Modo "Manual")
F6 - Retornar a interfaz gráfica.

Créditos y Dependencias: Este software utiliza el motor de escaneo Nmap® (nmap.org). 
Nmap es un software gratuito y de código abierto bajo la licencia NPSL.
