# quickmap
QuickMap es una interfaz gráfica de usuario desarrollada a modo de optimizar el uso de la herramienta a través del pad numérico del teclado.

[Manual]

Enter - Escanear.
Supr. - Limpiar.
F12 - Guardar Log.
F1 - Escaneo Rápido. 
F2 - Escaneo Intenso.
F3 - Descubrir Red.

F5 - Ingresar a terminal. (Modo "manual")
F6 - Retornar a interfaz gráfica.

Créditos y Dependencias: Este software utiliza el motor de escaneo Nmap® (nmap.org). 
Nmap es un software gratuito y de código abierto bajo la licencia NPSL. 
Agradecemos a la comunidad de Nmap por su increíble motor de seguridad.
